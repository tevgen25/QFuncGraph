## Детальный алгоритм работы

### 1. Запуск приложения (main.cpp)

```
main(int argc, char **argv)
├── Создание QApplication app(argc, argv)
├── Создание AppWindow *appWindow = new AppWindow()
├── Установка размера окна: appWindow->resize(800, 600)
├── Показ окна: appWindow->show()
└── Запуск цикла событий: return app.exec()
```

### 2. Конструктор главного окна (AppWindow::AppWindow)

```
AppWindow::AppWindow(QWidget *parent)
├── Вызов конструктора базового класса: QMainWindow(parent)
├── Создание центрального виджета
│   ├── QWidget *centralWidget = new QWidget(this)
│   └── setCentralWidget(centralWidget)
├── Создание элементов интерфейса:
│   ├── Поле ввода функции: functionInput = new QLineEdit(this)
│   ├── Поле области определения: domainInput = new QLineEdit(this)
│   ├── Кнопка "Рассчитать": calculateButton = new QPushButton(this)
│   ├── Кнопка "Построить график": plotButton = new QPushButton(this)
│   └── Виджет графика: plotWidget = new QCustomPlot(this)
├── Настройка графика:
│   ├── Установка подписей осей
│   ├── Создание и настройка тикеров осей
│   ├── Установка белого фона
│   └── Настройка интерактивности
├── Создание компоновки:
│   ├── Создание панели ввода inputPanel
│   ├── Создание вертикального layout для панели inputPanelLayout
│   ├── Добавление элементов в inputPanelLayout:
│   │   ├── Метка "Функция:"
│   │   ├── Поле functionInput
│   │   ├── Метка "Область определения:"
│   │   ├── Поле domainInput
│   │   └── Горизонтальный layout с кнопками
│   ├── Ограничение высоты панели: inputPanel->setMaximumHeight(150)
│   ├── Создание основного layout: mainLayout
│   ├── Добавление inputPanel и plotWidget в mainLayout
│   └── Установка пропорций: setStretch(0,1) и setStretch(1,4)
└── Подключение сигналов к слотам:
    ├── connect(calculateButton → clicked() → onCalculateClicked())
    └── connect(plotButton → clicked() → onPlotClicked())
```

### 3. Алгоритм расчета функции (onCalculateClicked)

```
AppWindow::onCalculateClicked()
├── Получение текста из полей ввода:
│   ├── QString funcStr = functionInput->text().trimmed()
│   └── QString domainStr = domainInput->text().trimmed()
├── Проверка заполнения полей:
│   ├── Если funcStr.isEmpty() ИЛИ domainStr.isEmpty()
│   │   └── Показать сообщение об ошибке → Выход
│   └── Иначе продолжить
├── Разбор области определения:
│   ├── QStringList parts = domainStr.split(' ', Qt::SkipEmptyParts)
│   ├── Если parts.size() != 2
│   │   └── Показать сообщение об ошибке → Выход
│   └── Иначе продолжить
├── Преобразование в числа:
│   ├── double xMin = parts[0].toDouble(&ok1)
│   ├── double xMax = parts[1].toDouble(&ok2)
│   ├── Если !ok1 ИЛИ !ok2 ИЛИ xMin >= xMax
│   │   └── Показать сообщение об ошибке → Выход
│   └── Иначе продолжить
├── Инициализация парсера:
│   ├── mu::Parser parser
│   ├── double var_x = 0.0
│   ├── parser.DefineVar("x", &var_x)
│   └── parser.SetExpr(funcStr.toStdString())
├── Расчет значений функции:
│   ├── Очистка массивов: xValues.clear(), yValues.clear()
│   ├── const int N = 500
│   ├── double step = (xMax - xMin) / (N - 1)
│   └── Цикл for i от 0 до N-1:
│       ├── var_x = xMin + i * step
│       ├── double y = parser.Eval()
│       ├── xValues.push_back(var_x)
│       └── yValues.push_back(y)
└── Обработка результатов:
    ├── Если успешно: показать сообщение "Функция рассчитана"
    └── Если ошибка: показать сообщение об ошибке парсера
```

### 4. Алгоритм построения графика (onPlotClicked)

```
AppWindow::onPlotClicked()
├── Проверка наличия данных:
│   ├── Если xValues.empty() ИЛИ yValues.empty()
│   │   └── Показать сообщение об ошибке → Выход
│   └── Иначе продолжить
├── Подготовка графика:
│   ├── Очистка старых графиков: plotWidget->clearGraphs()
│   └── Добавление нового графика: plotWidget->addGraph()
├── Установка данных:
│   ├── Создание QVector из std::vector:
│   │   ├── QVector<double>(xValues.begin(), xValues.end())
│   │   └── QVector<double>(yValues.begin(), yValues.end())
│   └── plotWidget->graph(0)->setData(xVector, yVector)
├── Настройка внешнего вида:
│   ├── Установка синего цвета: setPen(QPen(Qt::blue, 2))
│   └── Автомасштабирование: plotWidget->rescaleAxes()
└── Обновление отображения: plotWidget->replot()
```

## Заключение

Эта структура обеспечивает четкое разделение ответственности между компонентами программы и надежную обработку пользовательского ввода. Программа следует принципам модульности, где каждый компонент отвечает за свою конкретную задачу, что облегчает поддержку и расширение функциональности.

**Ключевые принципы архитектуры:**
- Разделение интерфейса и логики
- Модульная структура компонентов  
- Централизованная обработка ошибок
- Четкий поток данных между модулями
- Инкапсуляция функциональности в отдельных методах
