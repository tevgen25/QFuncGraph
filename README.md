# QFuncGraph - Графический построитель функций

## Описание программы

QFuncGraph - это десктопное приложение на C++/Qt для построения графиков математических функций. Программа позволяет пользователям вводить математические выражения и визуализировать их в виде графиков с настраиваемой областью определения.

## Основные возможности

- **Ввод математических функций** с поддержкой стандартных операций и функций
- **Настройка области определения** (диапазона по оси X)
- **Визуализация графиков** с помощью библиотеки QCustomPlot
- **Интерактивное управление графиком** - масштабирование, перемещение, выделение
- **Автоматическое масштабирование** под данные
- **Валидация ввода** с информативными сообщениями об ошибках

## Поддерживаемые математические функции

Программа использует библиотеку muParser, которая поддерживает:
- Базовые операции: `+`, `-`, `*`, `/`, `^` (возведение в степень)
- Тригонометрические функции: `sin(x)`, `cos(x)`, `tan(x)`
- Обратные тригонометрические: `asin(x)`, `acos(x)`, `atan(x)`
- Гиперболические: `sinh(x)`, `cosh(x)`, `tanh(x)`
- Логарифмические: `log(x)` (натуральный), `log10(x)` (десятичный)
- Экспоненциальные: `exp(x)`
- Другие: `sqrt(x)`, `abs(x)`

## Сборка и запуск в CLion

### Предварительные требования

- **CLion 2023.3+** (рекомендуется 2025.2)
- **Qt 5.14.2+** (MinGW версия)
- **MinGW-w64** (должен быть установлен с Qt)
- **CMake 3.10+**

### Настройка окружения в CLion

1. **Откройте проект в CLion:**
   - File → Open → Выберите папку проекта
   - CLion автоматически обнаружит CMakeLists.txt

2. **Настройте инструментарий (Toolchains):**
   - File → Settings → Build, Execution, Deployment → Toolchains
   - Добавьте MinGW:
     - Environment: MinGW
     - Путь к компилятору: `D:/Qt/Qt5.14.2/Tools/mingw730_64/bin/g++.exe`
   
   **ИЛИ используйте автоматическое определение:**
   - CLion обычно автоматически находит MinGW из установки Qt

3. **Настройте профили сборки CMake:**
   - File → Settings → Build, Execution, Deployment → CMake
   - Убедитесь, что в Build type установлен `Release` или `Debug`
   - Параметры CMake: `-DCMAKE_PREFIX_PATH="D:/Qt/Qt5.14.2/5.14.2/mingw73_64/lib/cmake"`

### Сборка проекта

1. **Выберите конфигурацию сборки:**
   - В правом верхнем углу выберите `QFuncGraph | Release`

2. **Соберите проект:**
   - Build → Build Project (Ctrl+F9)
   - Или нажмите кнопку ▶️ (Run)

3. **Проверьте сборку:**
   - В окне сборки не должно быть ошибок
   - Исполняемый файл создается в `cmake-build-release/QFuncGraph.exe`

### Запуск приложения

#### Способ 1: Запуск через CLion
- Нажмите кнопку ▶️ (Run) или Shift+F10
- CLion автоматически запустит собранное приложение

### Решение частых проблем в CLion

#### Проблема 1: Qt не находится
```
CMake Error at CMakeLists.txt:10 (find_package):
  Could not find a package configuration file provided by "Qt5" with any of
  the following names:
```

**Решение:**
- Убедитесь, что `CMAKE_PREFIX_PATH` указан правильно в CMakeLists.txt
- Проверьте путь к Qt в настройках CMake в CLion

#### Проблема 2: Ошибки линковки muParser
```
undefined reference to `mu::ParserCallback::ParserCallback'
```

**Решение:**
- Убедитесь, что файл `muParserCallback.cpp` включен в CMakeLists.txt
- Выполните Build → Clean and Rebuild Project

#### Проблема 3: Отсутствующие DLL при запуске
```
Process finished with exit code -1073741511 (0xC0000139)
```

**Решение:**
- См. раздел "Ручной запуск" выше
- Или добавьте автоматическое копирование DLL в CMakeLists.txt

## Использование приложения

1. **Введите функцию** в первое текстовое поле (используйте 'x' как переменную)
2. **Задайте область определения** во втором поле (два числа через пробел: x_min x_max)
3. **Нажмите "Рассчитать"** для вычисления значений функции
4. **Нажмите "Построить график"** для отображения графика
5. **Взаимодействуйте с графиком** используя мышь для навигации
